# Department Structure — FOP (Faculty of Pharmacy)

## Scope
This document describes the academic/batch structure of the Faculty of Pharmacy, for use as reference input when generating the timetable (FOP - Faculty Operating Plan / schedule).

**Currently designing for the Odd Semester:**
- B.Pharm — Semesters 1, 3, 5, 7
- M.Pharm — Semesters 1, 3

---

## Courses Offered
1. B.Pharm (Bachelor of Pharmacy)
2. M.Pharm (Master of Pharmacy)
3. Pharm D (Doctor of Pharmacy)

---

## 1. B.Pharm

| Attribute | Detail |
|---|---|
| Program type | Semester-based |
| Max students per year | 120 |
| Divisions per year | 2 — Division A, Division B |
| Batches per semester | 2 (every semester, every year) |
| Classrooms required | 2 per year (1 per division) |

**Notes:**
- Every year of B.Pharm (across all semesters) is split into two divisions: **Division A** and **Division B**.
- Each division needs its own classroom, so **2 classrooms per year** are required at all times.

---

## 2. M.Pharm

| Attribute | Detail |
|---|---|
| Program type | Semester-based |
| Duration | 2 years (4 semesters total) |
| Specializations | 9 |
| Batches per semester | 9 (1 batch per specialization) |
| Max students per batch | 15 |

**Notes:**
- Each of the 9 specializations runs as its own independent batch for any given ongoing semester.
- Batch size is capped at 15 students.

---

## 3. Pharm D

| Attribute | Detail |
|---|---|
| Program type | Annual (NOT semester-based) |
| Duration | 5 years |
| Batches | 5 — one per year (Year 1, Year 2, Year 3, Year 4, Year 5) |
| Max students per batch | 40 |

**Notes:**
- Pharm D does not follow a semester system; scheduling is done on an annual/yearly basis.
- Each year of the program = 1 batch, capped at 40 students.

---

## Class Duration Standards

| Class Type | Duration |
|---|---|
| Theory class | 1 hour |
| Practical class | 3 hours |
